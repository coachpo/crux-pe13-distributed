Start with the [repository README](README.md), [standard-runner acceptance and rerun guide](docs/standard-runner-rom-build-acceptance-2026-11-05.md), and [Dev OTA guide](docs/dev-ota.md). Keep stock-ABL release builds (R6 was deleted on 2026-11-07) and the local OrbStack direct-install path out of this pipeline.

Private inputs come only from the two pinned GitHub snapshot repositories through `CRUX_SOURCE_SNAPSHOTS_TOKEN`; build artifacts, logs and Dev prereleases in this repository are public. The admitted graph summary, index receipt and pack registry under `docs/evidence/` are consumed build inputs. - Pass the successful cold compile run as `build_run` to [assemble-standard.yml](.github/workflows/assemble-standard.yml), and the matching successful assembly run as `assembly_run` to [release-dev.yml](.github/workflows/release-dev.yml). Release admission needs both the assembly artifact and its compile summary. Do not manually upload or repackage accepted ROM images, use local outputs as inputs, or restore the October workflows removed on 2026-11-07.
