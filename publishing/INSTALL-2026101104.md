# Crux PE13 R6 自建 OTA 候选版安装说明

适用设备：Xiaomi Mi 9 Pro 5G（crux）。使用原厂 ABL、官方分区、已解锁
bootloader 和 PE 公共产品的 v2 数据布局。保留 bootloader 解锁状态。
固件参考为 MIUI V13.0.1.0.RFXCNXM / Android 11；安装包保留现有固件。

本候选版用于验证云端编译、签名、发布与在线更新能力。电话、相机、指纹、
待机及其他硬件功能和日用稳定性没有获得完整认证。操作前备份个人数据。
不能把 MIUI 数据或旧 v1 metadata 直接恢复到 v2 PE 数据布局。

## 保留数据升级（R2/R3/R4/R5 用户）

R6 `2026101104` 包含自建 Updates 客户端 2。已有 R2、R3、R4、R5
或兼容的 v2 PE 用户可使用签名全量 ZIP 手动升级到 R6，保留数据：

1. 下载 R6 签名 ROM ZIP，并核对对应 Release 的 SHA256。
2. 从运行中的 ROM 执行 `adb reboot recovery`，或使用已验证可用的
   Recovery 入口。
3. 在匹配的公共 PE Recovery 中选择 Apply update / Apply from ADB，
   执行 `adb sideload ROM_FILE.zip`。
4. 安装成功后重启系统，不执行 Format Data、WipeData 或 metadata 擦除。

也可使用对应的同源 fastboot 包。手机进入 bootloader fastboot 后，在解压的
包目录执行 `python3 flash_crux.py --serial YOUR_SERIAL`。工具核验设备、
实际解锁状态和容量，刷写六个 Android 镜像后重启，保留 userdata、metadata
和 cache。任何刷写失败都会停止；修复连接后可重新运行同一完整包。

## 在线 OTA

在包含客户端 2 的兼容版本中进入设置 → 系统 → 系统更新。

1. 连接能访问 GitHub Pages 和 GitHub Releases 的网络，检查新版本。
2. 下载更新；客户端检查下载摘要及可信 OTA 签名。
3. 点击安装并确认。系统准备更新包，自动进入 PE Recovery 安装，再返回 ROM。
4. 启动后确认版本已更新。正常同系列升级保留数据，不需要手动选择 Recovery 菜单。

版本信息由 https://coachpo.github.io/crux-pe13-ota/ 提供，签名包和说明保存在
对应 GitHub Release。只有通过兼容性和签名检查的包才可安装。下载取消、
网络中断或校验失败时，在更新界面按提示重新下载；不要用手工 BCB 或 raw
分区写入替代安装流程。

## 首次安装与救援

首次从 MIUI 或不兼容的数据布局安装，需要使用匹配公共 PE Recovery 的
Format Data / WipeData 流程，这会删除用户数据。该流程与保留数据升级不同。
请按所选版本的首次安装说明操作；物理按键组合和所有 TWRP 版本未获本候选版认证。

系统无法启动但原厂 ABL fastboot 仍可进入时，使用对应的完整 fastboot 包
恢复 Android 镜像。该工具不负责解锁、重新锁定、固件、GPT 或 EDL 修复。
恢复旧系统版本可能不兼容较新的数据；回官方 ROM 时按官方完整包说明备份并重置，
不要混用旧 PE metadata 和当前 v2 userdata。

## 源码

每个 Release 提供确切源码版本、增量源码补丁和构建身份。内核、Recovery
和设备树的基础源码来自 coachpo 的 Crux 仓库；签名私钥不随发布分发。
